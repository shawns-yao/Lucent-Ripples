# 一池清漾 · 自然生长与真实天象版（1.2.0）

PixiJS + WebGL 的轻微倾斜俯视鱼池。支持卡通与自然写实两种风格，44 条鱼独立游动，荷花按真实经过时间生长；使用 2.5D 图层和纵向投影，不是完整 3D 场景。

## Windows：最快打开

1. 解压 ZIP，进入其中的 `pixi-fish-pond` 文件夹
2. 双击 `artifacts/fish-pond.html`

这个 HTML 已内嵌所有图片和脚本，不需要安装或联网。点击右上角面板，可以切换天气、昼夜、画面风格和树木季节。荷叶和莲花自然生长，手机竖屏可拖动查看池塘全景。离线 HTML 的天气明确标为“演示”，不会取得真实天气，也不会请求定位。

如果双击方式被浏览器策略限制，使用下方本地服务方式。需要支持 WebGL 的现代 Chrome 或 Edge。

## Windows PowerShell：运行源码

先安装 Node.js 22.12 或更新版本（建议当前 Node.js LTS）。在解压后的 `pixi-fish-pond` 文件夹打开 PowerShell：

```powershell
npm.cmd ci
npm.cmd run dev
```

打开终端显示的地址，通常是 http://127.0.0.1:5173/ 。使用 `npm.cmd` 可以避免 PowerShell 对 `npm.ps1` 的执行策略提示；无需修改系统安全策略。

仅查看已构建的版本：

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd start
```

打开 http://127.0.0.1:8787/ 。未配置凭据时仍可使用全部演示场景。

## 已实现

- 修复 `src/water.js` 顶点、片元着色器的共享 `uInputSize` 精度：两处均为 `uniform mediump vec4 uInputSize;`
- 轻微倾斜俯视的 2.5D 构图、岸边树木及蜂巢、随风轻摆
- 白天少量蜜蜂、蝴蝶；蝴蝶有变向、滑翔和停落，冬景隐藏蜜蜂、蝴蝶、萤火虫和青蛙
- 夜间萤火虫、随波打散的柔和月光倒影；参考月面照片的细微明暗，月相、云量和地平线影响可见性
- 白天使用缓慢流动的曲线水纹和局部细波，卡通版减少细碎光纹；阴雨雪会削弱直射光
- 雨雪沿俯视相机的高度方向接近水面，只有短距离投影和轻微风偏，不再横穿整个池面
- 雨滴触水时出现同一落点的水珠与扩散圆环，并局部折射水面；荷叶和岸石上不生成水面圆环
- 云量、降水、昼夜影响水面亮度与色调；天气平滑过渡
- 不规则雪片翻转飘落，区分落水、岸石和荷叶反馈；四角霜晶向内延伸，中央保持清透，积雪和薄冰随冷却、回暖变化
- 少量螃蟹在浅水、岸石附近横向爬行、停留和藏身；光滑绿色青蛙在荷叶、石头和水面间活动，落点预留避让，游到边缘后跃上
- 自动昼夜、太阳/月亮方位使用真实日期和所选地点；未选地点时明确使用北京参考坐标。白昼/月夜按钮是有标记的固定天象预览
- 鱼各自巡游、滑行、短暂加速和静止休息；白天晚上都可能休息，没有整群统一睡眠。巡游基础速度 44–78 世界单位/秒；默认两分钟仿真平均约 47，旧版约 27.3，整体约快 1.72 倍
- 新莲花在合适水域随机落点，互相留出空间，首次保存后位置不会每帧或刷新改变；最多 8 株
- 已移除生长预览和重新发芽控制；按保存的出生时间与真实经过时间计算，暂停动画、关闭网页、天气切换均不会停表或加速
- 点击水面吸引附近的鱼；空格暂停，F 全屏；输入和按钮焦点不会误触快捷键

原背景中的两朵固定粉色莲花已去掉；原有静态绿色荷叶与岸景保留。所有粉色莲花均来自独立生长图层。

### 风格、季节与窗口适配

- 默认卡通风格，使用金鱼、小丑鱼等六种清晰造型；自然写实风格保留锦鲤、细腻池底和植物纹理。切换保留鱼、青蛙状态及荷花生长进度，选择保存在当前浏览器
- 春季树叶新绿、夏季深绿、秋季金黄，冬季切换为覆霜枝干与蜂巢；默认按北半球月份变化，也可手动预览。低温或结冰优先显示冬景。树木季节预览不会直接改变天气或冻住池塘
- 结冰是视觉近似：演示天气加快冷却以便观察，真实天气模式缓慢累积；没有真实水温或历史低温数据，不代表池塘实际结冰状态
- 宽高比例接近池塘的窗口完整缩放；手机竖屏及比例差异较大的窗口铺满，并支持拖动或方向键查看全景。拖动不会触发点击水波，岸石和荷叶也不会生成普通水面圆环
- 绘制最长边不超过 2560 像素，总预算约 260 万像素，像素密度最高 1.5；慢帧持续出现时降低画质，页面隐藏时停止动画。鱼网格保留独立变形并参与批处理，风格素材按需加载并缓存

### 莲花生长与保存

- 固定展示阶段：萌叶后约第 1 天幼叶、第 3 天展叶、第 7 天花苞、第 10 天半开、第 12 天盛开；阶段间平滑过渡。这是慢节奏视觉模型，不是物种生物学预测，不模拟季节性衰败
- 第一次打开时，初始化四株不同起始阶段的植株，让画面同时有幼叶和花；另外四个种点约在首次打开后 3、7、12、18 天自然出现。并不声称页面在首次打开前已经真实运行
- 保存随机位置、种点日期和种子，使用当前浏览器的 localStorage。刷新或同一地址重新打开恢复同一池；初次保存后约每分钟保存时钟进度，关闭页面也保存
- 生长时钟不由帧数、天气预览或暂停按钮控制；正常关闭数日再打开会补上真实经过时间。设备时钟向后调不让植株倒退；向前调会影响成长进度
- 同一浏览器、同一网址/离线文件地址保存进度。无痕模式、清除网站数据、更换浏览器、源站或离线文件路径可能成为新池塘；存储被禁用时界面会提示无法持久保存

### 太阳、月亮与光斑

- 自动模式每秒按真实时间更新近似太阳/月亮高度角、方位角和月相。默认北朝上，位置来自确认的区县或主动定位；未选位置明确标记为“北京参考坐标”
- 月亮在地平线下或接近新月时，自动模式不会强行显示倒影。月夜预览明确标注满月示意，便于随时查看碎月光和水波效果
- 使用离线 SunCalc 1.9 低阶公式，不请求天文服务。包含标准月球折射，未模拟地形遮挡、观测者海拔、月球视差或精确气象折射，不用于导航或精确升落时预测
- 背景没有标定真实相机，因此倒影位置采用固定北向的艺术投影，并随真实天体方位移动；不声称是校准的光学反射模拟。窄屏可能裁掉真实倒影所在水域，可拖动查看；示意预览放在池塘中部
- 日间闪光由水面局部波纹变化驱动，晴天明显，阴雨雪较弱；冰面覆盖处减弱水面波动和反光
- 公式来源与 BSD 许可保留在 `src/celestial.js`；参考 https://github.com/mourner/suncalc/tree/v1.9.0

## 和风天气：本地安全配置

已接入服务端适配代码，尚未配置真实凭据，也未进行真实接口联调。API Host 已使用提供的 `np3tegphmc.re.qweatherapi.com`；API key 留空。不要把真实 key、JWT 或私钥发到聊天、写进前端、提交到 Git，或放进分享的 ZIP。

### 1. 创建本地环境文件

```powershell
Copy-Item .env.example .env
notepad .env
```

在自己的电脑上填写 `QWEATHER_API_KEY=`，或者填写 `QWEATHER_JWT=`。两者只填一个。JWT 是在服务端安全签发的 Ed25519 令牌，本示例不会生成私钥或签发长期凭据；令牌到期前须由你安全更新并重启服务。

`.env` 已在 `.gitignore` 中，交付的 ZIP 只包含 `.env.example`，不含实际 `.env`。环境变量不得使用 `VITE_` 前缀，因为这类变量会进入浏览器构建。

### 2. 运行带天气服务的构建

```powershell
npm.cmd ci
npm.cmd run build
npm.cmd run start:weather
```

打开 http://127.0.0.1:8787/ 。打开天气面板，点击“使用当地天气”，再由你在浏览器提示中决定是否授权；或者手动输入城市 + 区/县（如“北京市”与“朝阳区”，也支持合写“北京市朝阳区”）、查找并选择正确候选。

开发时可开两个 PowerShell 窗口：一个 `npm.cmd run weather`，另一个 `npm.cmd run dev`，然后访问 5173 地址。Vite 会把同源 `/api` 请求代理到 8787。

正式网站需 HTTPS 才能定位；本机 localhost/127.0.0.1 通常属于浏览器允许的安全上下文。服务默认只监听 `127.0.0.1`，没有自动部署或发布。对外部署前应补充访问控制、全局调用预算与服务器限流，避免访客流量耗尽天气额度。

### 数据与隐私

- 不在页面加载时定位，不持续跟踪；只在主动点击后请求一次位置
- 经纬度在浏览器和服务端都取两位小数，约公里级；发送给本应用服务及和风天气用于查询
- 无位置历史、用户画像、定位持久化或访问日志。服务端仅短期按粗略地点缓存天气，不绑定访问者
- 定位拒绝、失败、超时均可改为手选城市；城市/区县存在同名情况，必须选择候选项；按行政隶属筛选，不把查不到的区县静默替换成市中心
- 浏览器不持有和风凭据，只访问同源服务端
- 天气共享缓存 10 分钟，合并并发请求；失败时最多保留不足 1 小时的已标注旧数据，鉴权失败停止上游重试
- 页面隐藏时不主动刷新；返回页面且数据过期时更新。城市/区县 GeoAPI 结果不缓存；手动输入的地名会发送给和风天气
- 保留官方署名与返回的 `metadata.attributions`。新接口无观测时刻字段，因此界面标记“上次获取”，不冒充观测时间
- API 调用使用你的账户额度，可能计费；本次开发与测试没有调用真实接口

### 使用的官方接口

- 实时天气：`GET /weather/v1/current/{latitude}/{longitude}?lang=zh`（纬度在前）
- 城市查找：`GET /geo/v2/city/lookup?location=名称&number=20&lang=zh`，带上父城市 `adm=城市` 和中国区县查询的 `range=cn`
- `precipitation.type / intensity.value` → 雨雪类型、强度（mm/h）
- `wind.speed.value / direction.degree` → 风速（m/s）、来向
- `cloudCover` → 云量（0–1），`temperature.value` → 温度（℃）

官方文档（2026-10-02 核对）：

- https://dev.qweather.com/en/docs/api/weather/weather-current/
- https://dev.qweather.com/en/docs/api/geoapi/city-lookup/
- https://dev.qweather.com/en/docs/configuration/api-host/
- https://dev.qweather.com/en/docs/configuration/authentication/
- https://dev.qweather.com/en/docs/best-practices/cache/
- https://dev.qweather.com/en/docs/terms/attribution/

旧 `/v7/weather/now` 文档已标记将弃用，新适配器不使用旧字段或旧共享 API 域名。

## 文件结构

- `src/main.js`：PixiJS 场景、2.5D 投影、鱼网格和交互
- `src/scene-style.js`：两套风格素材、按需加载、切换与选择保存
- `src/tree-seasons.js`：树叶季节滤镜、日期与手动季节选择
- `src/frame-budget.js`：帧耗时采样与绘制质量调整
- `src/simulation.js`：各鱼独立速度、休息、加速、点击兴趣与边界
- `src/water.js`：曲线水纹、局部雨滴折射、太阳光斑、碎月光及四角薄霜
- `src/celestial.js`：真实时间和选定经纬度的近似太阳/月亮方位、月相
- `src/lotus-growth.js`：随机种点、时间戳生长、持久存储
- `src/precipitation.js`：降水高度轨迹与一致落点
- `src/pond-surface.js`：合适水域、荷叶/岸石遮挡
- `src/pond-climate.js`：冷却、回暖、积雪及冰层范围
- `src/pond-life.js`：螃蟹动作、青蛙跳跃与游泳、落点避让
- `src/weather.js`：天气归一化、平滑过渡和昼夜亮度
- `src/weather-effects.js`：雨、雪、新荷叶/莲花渲染
- `src/shore-life.js`：岸树、蜂巢、蜜蜂、蝴蝶、萤火虫
- `src/weather-ui.js`：天气选择、主动定位、城市选择、状态和署名
- `server/weather-server.mjs`：本地静态服务和和风代理
- `.env.example`：非秘密主机名与空凭据模板
- `public/assets/`：全部图像，包括新透明植物与岸边生物图集
- `artifacts/fish-pond.html`：单文件离线演示
- `tests/`：自动化测试及可选浏览器测试

全部视觉素材随包提供，运行演示无需外部图片服务。
