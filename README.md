# Lucent Ripples · 一池清漾

PixiJS + WebGL 的轻微倾斜俯视鱼池。支持卡通与自然写实两种风格，春、夏、秋、冬分别显示 32、44、28、10 条鱼，荷花按真实经过时间生长；使用 2.5D 图层和纵向投影，不是完整 3D 场景。

可在浏览器中运行，也可导入 Wallpaper Engine 作为动态壁纸。离线版本自带脚本和图像，无需启动开发服务器；默认 30 帧，可调整为 60 帧，绘制最高边长限制为 2560 像素。

## 从源码开始

需要 Node.js 22.12 或更高版本、npm，以及支持 WebGL 的浏览器。Windows PowerShell 使用以下命令：

```powershell
git clone --branch main https://github.com/shawns-yao/Lucent-Ripples.git
cd Lucent-Ripples
npm.cmd ci
npm.cmd run dev
```

打开终端显示的地址，默认是 http://127.0.0.1:5173/ 。演示天气不需要 `.env`。真实天气为可选功能，按下方“和风天气：本地安全配置”配置服务端。

| 目的 | 命令 | 产物或入口 |
| --- | --- | --- |
| 开发预览 | `npm.cmd run dev` | 本地 5173 端口 |
| 生产构建 | `npm.cmd run build` | `dist/` |
| 浏览生产页面 | `npm.cmd start` | 本地 8787 端口，需先构建 |
| 单文件离线演示 | `npm.cmd run standalone` | `artifacts/fish-pond.html` |
| Wallpaper Engine 打包 | `npm.cmd run wallpaper` | `artifacts/wallpaper-engine/` |

拖动可浏览被裁切的池塘，点击活水吸引鱼群；空格暂停，F 切换全屏。网页右上角可调整天气、季节、昼夜及风格；壁纸模式通过 Wallpaper Engine 属性调整。

## 四季景观与半冻结冬池

春季显示较小的嫩绿生长荷叶与花苞，夏季叶片和荷花最繁盛，秋季荷叶变为黄褐色、收起花朵并漂落少量树叶。冬季隐藏绿色荷叶，保留残荷、枯草和枝干，鱼减速下潜；其余鱼进入休眠，停止绘制及邻居计算，换季恢复，植物出生日期不变。

冬季冰层从岸边连成片，中央保留不对称狭长活水。冰边有透明过渡，靠岸更厚；冻结流纹、细裂纹与少量气泡保持静止，薄雪仅局部出现。当前 20 世界单位网格观察约 71.5% 水域冻结，属于美术预设，不是水温模型。冰面禁止点击水波和雨滴涟漪。活水薄雾独立缓慢漂移，日出日落附近较浓、白天较淡，大风和降雨削弱雾气；复用同一水面滤镜。

2026-10-05 定向测试：真实页面两种风格共 8 组季节切换，鱼量、植物状态与生长日期检查通过；930 个雨滴波纹均落在活水区。32 秒青蛙观察记录 12 次跳跃，未发现花朵重叠或站立冲突。桌面和 390×844 冬景截图已检查。2K 本机预览为约 260 万绘制像素，240 帧平均间隔约 16.9 毫秒，完整画质。薄雾时间变化与暂停通过观察，但未等待实际日出日落验证浓淡变化。

离线壁纸冒烟测试：30／60 帧各约 3.2 秒采样 94／190 帧，暂停后零新增帧且薄雾计时停止，无外部素材请求。生产构建及两种离线打包通过。未验证原生 Wallpaper Engine、Edge、手机真机、跨月变化或长期性能，未运行全量单元测试；上述结果来自内置浏览器。

最新岸冰材质修订（2026-10-05）：冰层显示范围不再按鱼的活动多边形裁切，改用冬季底图颜色生成浅水与石头接触遮罩。移除大片程序霜斑、孤立黑线和冰下模糊采样，使用 `public/assets/ice-material.webp` 的静态裂纹、气泡和霜晶。贴图为 1024×1024、306040 字节，复用既有水面滤镜，并内嵌到两种离线入口。沿岸遮罩为美术近似，尚未逐像素标注所有岸石。

本次定向测试：两种风格及手机尺寸截图已检查，分段观察的 697 个雨滴波纹均在活水，冰面与活水点击分别拒绝和接受，夏季恢复 44 条鱼且冰量为零。最初整批浏览器检查超时，未计为通过。离线冒烟测试：本机 2K、60 帧设置约 4.2 秒采样 249 帧，240 帧平均间隔约 16.9 毫秒，保持单水面滤镜、完整画质，暂停零新增帧，无外部素材请求。未验证原生 Wallpaper Engine、Edge、手机真机及长期表现，未重跑全量测试。

## Windows：直接打开离线演示

1. 下载或克隆仓库，进入项目根目录
2. 双击 `artifacts/fish-pond.html`

这个 HTML 已内嵌所有图片和脚本，不需要安装或联网。点击右上角面板，可以切换天气、昼夜、画面风格和场景季节。荷叶和莲花自然生长，手机竖屏可拖动查看池塘全景。离线 HTML 的天气明确标为“演示”，不会取得真实天气，也不会请求定位。

如果双击方式被浏览器策略限制，使用下方本地服务方式。需要支持 WebGL 的现代 Chrome 或 Edge。

## Wallpaper Engine 动态壁纸

已购买 Wallpaper Engine 时，使用独立的 `artifacts/wallpaper-engine` 文件夹；它只包含壁纸入口、项目配置和预览图，图片与脚本均已内嵌，不依赖开发服务器。

1. 在 Wallpaper Engine 中选择“打开壁纸”→“打开离线壁纸（动态）”，选择该文件夹内的 `project.json`。
2. 在壁纸设置中选择画面风格、演示天气、昼夜、场景季节、画面适配及鼠标互动。默认 30 帧，可以切换为 60 帧；最终上限取壁纸选项和 Wallpaper Engine 全局帧率中的较小值。
3. 壁纸默认铺满屏幕，可拖动浏览裁切部分；“完整池塘”按比例缩小。画面不显示网页按钮、提示或标题，也不处理网页的暂停、全屏快捷键。

从源码重新生成壁纸文件夹：

```powershell
npm.cmd run wallpaper
```

需要在编辑器中继续修改时，可将该独立文件夹内的 `index.html` 拖到“创建壁纸”按钮。编辑器会复制整个文件夹，因此后续源码修改需要重新打包并更新编辑器中的副本。[官方导入说明](https://docs.wallpaperengine.io/en/web/first/gettingstarted.html)

最高绘制边长仍为 2560 像素，总像素预算约 260 万；慢帧降级按实际设定帧率判断。接收到 Wallpaper Engine 暂停回调或页面隐藏时停止渲染，恢复时清空旧帧耗时记录。该离线包使用演示天气，自动昼夜以真实时间和北京参考坐标计算，不请求定位或真实天气服务。

定向测试：通过实际壁纸 HTML 入口调用宿主的公开属性和暂停回调，检查 30／60 帧设置、全局 24 帧上限、停止与恢复、风格和冬景、鼠标互动开关、2K 和超宽屏铺满。30 帧本机浏览器预览在约 3.2 秒内采样 95 帧，保持完整画质；60 帧选项已接入，但该次预览采样不足以证明稳定达到 60 帧。冒烟测试：普通页面的控件、风格与昼夜切换正常。生产构建、普通离线及壁纸打包通过。尚未在 Wallpaper Engine 应用内导入验收，也未验证其桌面鼠标转发、多显示器和原生遮挡暂停。

- 修复 `src/water.js` 顶点、片元着色器的共享 `uInputSize` 精度：两处均为 `uniform mediump vec4 uInputSize;`
- 轻微倾斜俯视的 2.5D 构图、岸边树木及蜂巢、随风轻摆
- 白天少量蜜蜂、蝴蝶；升降与投影区分空中飞行和贴水活动。蝴蝶减速接近荷花，降落后停留、轻动翅膀再起飞；花朵落点跟随植株轻摆并独占预约，冬景隐藏蜜蜂、蝴蝶、萤火虫和青蛙
- 夜间萤火虫、随波打散的柔和月光倒影；参考月面照片的细微明暗，月相、云量和地平线影响可见性
- 中央偏左为渐变深水，岸边保持较浅的黄绿色；鱼的清晰度和投影偏移随水深缓慢变化。这是视觉近似，不代表真实水深测量
- 白天使用局部曲线光纹和细波，深水区更安静；鱼尾和风吹叶边最多保留 6 处弱扰动，复用记录并接入同一水面着色器。卡通版减少细碎光纹，阴雨雪削弱直射光
- 24 条鱼组成 8 个、每组 2～4 条的松散鱼群，其余 20 条独游；小群间歇穿过中央，部分独游鱼靠近荷叶后减速休息
- 雨雪沿俯视相机的高度方向接近水面，覆盖池塘及岸景；雨粒基准 1440，春雨预算在 1440～2880 间缓慢变化，夏雨 7200、秋雨 3600，春雨细短、夏雨粗长且下落轨迹更广。数字表示粒子周期的规模，部分粒子处于落地阶段；可见数量还受天气强度、画质和窗口裁切影响
- 雨滴触水时出现同一落点的水珠与扩散圆环，并局部折射水面；荷叶和岸石上不生成水面圆环
- 云量、降水、昼夜影响水面亮度与色调；天气平滑过渡
- 自然飘雪使用八种疏松雪粒纹理，远处细碎、较淡，近处少量柔和雪簇；雪粒池上限 1440，深度影响尺寸、透明度、落速和风偏。落水后缩小融化，岸石与荷叶接住雪；四角霜晶向内延伸，中央保持清透，积雪和薄冰随冷却、回暖变化
- 少量螃蟹在浅水、岸石附近横向爬行、停留和藏身；光滑绿色青蛙在荷叶、石头和水面间活动，落点预留避让，游到边缘后跃上。青蛙按花苞和花朵的实际大小避让，停留、跳跃路径及游泳返叶均保留身体与腿部空间
- 8 丛沉水植物集中在浅水，随水流轻摆，附近游鱼引起短暂偏摆；8 只小虾在各自小范围内爬行、停顿，受游鱼惊扰后短距离逃开
- 已移除水黾；最多 6 片花瓣从可开放的荷花附近出现，缓慢漂移、淡出，遇到叶片或岸边结束漂移
- 3 只蜻蜓采用细长分节身体和前后两对透明翅膀，前后翼不同步振动，持续变向飞行并保留高度和投影，不再降落。秋冬隐藏蜻蜓、蜜蜂、蝴蝶和萤火虫；暖季还按昼夜、风雨抑制活动。冬季进一步隐藏小虾和花瓣，水草转为低矮枯色
- 7 只蜜蜂使用独立身体与翅膀，在可用花朵、荷叶和蜂巢之间选择新目标；短暂停留后继续访花或返巢休息。与蝴蝶互斥预约花朵，冬季、夜晚和大雨隐藏，不再重复固定的往返轨迹
- 新增生态使用按风格缓存的小图集与批处理网格，不增加全屏滤镜；原有青蛙、蜜蜂及夜间萤火虫继续复用，蝴蝶离叶后的短途飞行收拢在植物附近
- 自动昼夜、太阳/月亮方位使用真实日期和所选地点；未选地点时明确使用北京参考坐标。白昼按钮为固定示意，月夜按钮为缓慢移动的满月示意
- 鱼各自巡游、滑行、短暂加速和静止休息；白天晚上都可能休息，没有整群统一睡眠。巡游基础速度 44–78 世界单位/秒；默认两分钟仿真平均约 47，旧版约 27.3，整体约快 1.72 倍
- 新生莲花最多 8 株，集中在中部偏右和右下两组；每组最多同时显示 2 朵花，结合 8 片大小不同的伴生叶形成疏密变化。位置带少量固定随机偏移，刷新后保留
- 已移除生长预览和重新发芽控制；按保存的出生时间与真实经过时间计算，暂停动画、关闭网页、天气切换均不会停表或加速
- 点击水面吸引附近的鱼；空格暂停，F 全屏；输入和按钮焦点不会误触快捷键。暂停时停止连续绘制，切换设置、调整窗口或平移全景时只刷新所需画面

原背景中的两朵固定粉色莲花已去掉；暖季保留静态绿色荷叶，冬季使用无绿荷叶底图。所有粉色莲花均来自独立生长图层。

### 风格、季节与窗口适配

- 默认卡通风格，使用俯视金鱼、小丑鱼等六种造型，背部高光和两侧鱼鳍与池塘视角一致；自然写实风格保留锦鲤、细腻池底和植物纹理。切换保留鱼、青蛙状态及荷花生长进度，选择保存在当前浏览器
- 固定荷叶按对应背景的实际叶面生成前景遮挡，填实叶内斑点并保留与水面连通的缺口；生长中的荷叶保留不透明底层，鱼从叶面下经过。遮挡只在风格首次加载时计算，随后缓存
- 春季树叶新绿、夏季深绿、秋季金黄，冬季切换为覆霜枝干与蜂巢；场景季节默认按北半球月份变化，也可手动预览。选择季节会调整演示降雨的规模与形态；冬季“雨”渐变为雨夹雪，“雪”保持纯雪，模拟温度和积雪同步变化
- 冬景采用半冻结冬池：固定绿荷叶、新生荷叶及花朵隐藏，只保留 3 片小残叶、5 根枯梗及局部枯草；背景、遮挡和落点判断同步切换。暖季恢复按真实时间计算的生长阶段，不改写植株出生时间、位置或存储记录
- 岸边形成连续厚冰，中央保留不规则活水；静态冰材质包含细裂纹、霜晶与气泡。冰区抑制波动、光纹及普通雨滴/点击水波，冰下鱼影更淡。冬季只显示 10 条鱼，其余休眠，暖季恢复
- 降雪仅在所选场景季节为冬季时显示；春、夏、秋禁用“雪”按钮，壁纸属性也遵守该限制。演示场景离开冬季立即清除雪粒、积雪和结冰；纯雪转为阴天，雨夹雪恢复对应季节的纯雨。真实天气保留接口返回的类型与温度，仅在非冬季场景中抑制雪粒和新增积雪，低温或结冰仍可使树木显示冬景
- 冬景的半冻结底色是季节美术预设；额外冷却和积雪仍由天气控制，演示天气加快冷却，真实天气模式缓慢累积。没有真实水温或历史低温数据，不代表池塘实际结冰状态
- 宽高比例接近池塘的窗口完整缩放；手机竖屏及比例差异较大的窗口铺满，并支持拖动或方向键查看全景。拖动不会触发点击水波，岸石和荷叶也不会生成普通水面圆环
- 绘制最长边不超过 2560 像素，总预算约 260 万像素，像素密度最高 1.5；慢帧持续出现时降低画质，页面隐藏时停止动画。雨雪使用批量粒子与共享纹理，屏幕外不绘制；雨滴圆环最多 240 个、局部水面折射最多 16 个，落点范围判断在粒子周期内缓存。鱼网格保留独立变形并参与批处理，风格素材按需加载并缓存
- 动作按实际经过时间推进，低帧率时拆成不超过 0.05 秒的小步计算鱼群、动物和气候，随后只绘制一次。单帧最多补算 2 秒，避免长时间卡顿后堆积计算；暂停或隐藏后的恢复不补算停留时间，植物生长仍按保存的真实时间计算

冬季底图为 `public/assets/pond-winter-natural.webp` 与 `public/assets/pond-winter-cartoon.webp`，均为 1672×941，两张合计约 431 KiB。通过内置 imagegen 编辑原有两套底图，提示要求为：移除所有绿荷叶及其阴影，填补相邻水底纹理，保留俯视构图、岸线、石头位置和原风格，不添加冰雪、生物或文字。冰层与残荷由场景独立绘制；两套前景遮挡和 418×236 的水域/冰片数据只计算一次并缓存，继续复用单层水面滤镜。

### 莲花生长与保存

- 固定展示阶段：萌叶后约第 1 天幼叶、第 3 天展叶、第 7 天花苞、第 10 天半开、第 12 天盛开；阶段间平滑过渡。这是慢节奏视觉模型，不是物种生物学预测；冬季枯色与休眠只影响显示，不模拟地下根茎或重新萌发生命周期
- 第一次打开时，初始化四株不同起始阶段的植株，让画面同时有幼叶和花；另外四个种点约在首次打开后 3、7、12、18 天自然出现。并不声称页面在首次打开前已经真实运行
- 保存簇群位置、种点日期和种子，使用当前浏览器的 localStorage。旧版分散种点首次打开会迁入簇群，保留全部出生时间、种子和生长时钟；刷新或同一地址重新打开恢复同一池。初次保存后约每分钟保存时钟进度，关闭页面也保存
- 生长时钟不由帧数、天气预览或暂停按钮控制；正常关闭数日再打开会补上真实经过时间。设备时钟向后调不让植株倒退；向前调会影响成长进度
- 同一浏览器、同一网址/离线文件地址保存进度。无痕模式、清除网站数据、更换浏览器、源站或离线文件路径可能成为新池塘；存储被禁用时界面会提示无法持久保存

### 太阳、月亮与光斑

- 自动模式每秒按真实时间更新近似太阳/月亮高度角、方位角和月相。默认北朝上，位置来自确认的区县或主动定位；未选位置明确标记为“北京参考坐标”
- 月亮在地平线下或接近新月时，自动模式不会强行显示倒影。月夜预览使用缓慢移动的满月示意，不表示当前月相或真实轨迹；倒影由不规则短碎光、柔和中心与水波扭曲组成，暂停时停止移动
- 使用离线 SunCalc 1.9 低阶公式，不请求天文服务。包含标准月球折射，未模拟地形遮挡、观测者海拔、月球视差或精确气象折射，不用于导航或精确升落时预测
- 背景没有标定真实相机，因此倒影位置采用固定北向的艺术投影，并随真实天体方位移动；不声称是校准的光学反射模拟。窄屏可能裁掉真实倒影所在水域，可拖动查看；示意预览放在池塘中部
- 日间闪光由水面局部波纹变化驱动，晴天明显，阴雨雪较弱；冰面覆盖处减弱水面波动和反光
- 公式来源与 BSD 许可保留在 `src/celestial.js`；参考 https://github.com/mourner/suncalc/tree/v1.9.0

### 数据与隐私

- 不在页面加载时定位，不持续跟踪；只在主动点击后请求一次位置
- 经纬度在浏览器和服务端都取两位小数，约公里级；发送给本应用服务及和风天气用于查询
- 无位置历史、用户画像、定位持久化或访问日志。服务端仅短期按粗略地点缓存天气，不绑定访问者
- 定位拒绝、失败、超时均可改为手选城市；城市/区县存在同名情况，必须选择候选项；按行政隶属筛选，不把查不到的区县静默替换成市中心
- 浏览器不持有和风凭据，只访问同源服务端
- 天气共享缓存 10 分钟，合并并发请求；失败时最多保留不足 1 小时的已标注旧数据，鉴权失败停止上游重试
- 页面隐藏时不主动刷新；返回页面且数据过期时更新。城市/区县 GeoAPI 结果不缓存；手动输入的地名会发送给和风天气
- 保留官方署名与返回的 `metadata.attributions`。新接口无观测时刻字段，因此界面标记“上次获取”，不冒充观测时间
- API 调用使用你的账户额度，可能计费；本次开发与测试没有调用真实接口

### 使用的官方接口

- 实时天气：`GET /weather/v1/current/{latitude}/{longitude}?lang=zh`（纬度在前）
- 城市查找：`GET /geo/v2/city/lookup?location=名称&number=20&lang=zh`，带上父城市 `adm=城市` 和中国区县查询的 `range=cn`
- `precipitation.type / intensity.value` → 雨雪类型、强度（mm/h）
- `wind.speed.value / direction.degree` → 风速（m/s）、来向
- `cloudCover` → 云量（0–1），`temperature.value` → 温度（℃）

## 文件结构

- `src/main.js`：PixiJS 场景、2.5D 投影、鱼网格和交互
- `src/scene-style.js`：两套风格素材、按需加载、切换与选择保存
- `src/tree-seasons.js`：树叶季节滤镜、日期与手动季节选择
- `src/frame-budget.js`：帧耗时采样与绘制质量调整
- `src/wallpaper.js`：壁纸模式、Wallpaper Engine 设置与暂停回调
- `Config/wallpaper-engine.json`：默认 30 帧及壁纸设置选项
- `scripts/build-wallpaper.mjs`：生成独立 Wallpaper Engine 项目文件夹
- `src/simulation.js`：空间网格邻居查询、小群巡游、独游与休息、点击兴趣和边界
- `src/pond-layout.js`：共享深浅水构图、荷花簇群和伴生叶坐标
- `src/surface-motion.js`：固定容量的鱼尾及叶边扰动记录
- `src/ecology-art.js`：按风格缓存的水草、小虾、蜻蜓、蜜蜂与花瓣图集
- `src/pond-vegetation.js`：浅水植物网格与局部游鱼扰动
- `src/pond-ecology.js`：小虾、漂浮花瓣及持续飞行蜻蜓的分层动作和季节联动
- `src/water.js`：曲线水纹、局部雨滴折射、太阳光斑、碎月光及四角薄霜
- `src/celestial.js`：真实时间和选定经纬度的近似太阳/月亮方位、月相
- `src/lotus-growth.js`：簇群种点、旧存档迁移、时间戳生长和持久存储
- `src/precipitation.js`：降水高度轨迹与一致落点
- `src/pond-surface.js`：合适水域、荷叶/岸石遮挡
- `src/surface-occlusion.js`：按背景叶片轮廓缓存前景遮挡，保留缺口并填实叶内斑点
- `src/pond-climate.js`：冷却、回暖、积雪及冰层范围
- `src/pond-life.js`：螃蟹动作、青蛙跳跃与游泳、落点避让
- `src/weather.js`：天气归一化、平滑过渡和昼夜亮度
- `src/weather-effects.js`：雨、雪、新荷叶/莲花渲染
- `src/shore-life.js`：岸树、蜂巢、蜜蜂、蝴蝶、萤火虫
- `src/weather-ui.js`：天气选择、主动定位、城市选择、状态和署名
- `server/weather-server.mjs`：本地静态服务和和风代理
- `.env.example`：非秘密主机名与空凭据模板
- `public/assets/`：全部图像，包括新透明植物与岸边生物图集
- `artifacts/fish-pond.html`：单文件离线演示
- `tests/`：自动化测试及可选浏览器测试

全部视觉素材随包提供，运行演示无需外部图片服务。
